📥 카글 노트북 다운로드

아래 버튼으로 노트북을 다운로드한 뒤, 카글에 업로드해서 실행하세요.

⬇️ Notebook (.ipynb) 다운로드 ⬇️ kernel-metadata.json 다운로드

🚀 카글 실행 가이드

  1. kaggle.com/code/new 접속 후 새 노트북 생성
  2. 우측 패널: Accelerator → GPU T4 × 1, Internet → ON
  3. 다운로드한 kaggle_wan22_t2v_param.ipynb 업로드 (File → Import)
  4. Add Data → "WAN22_DAON_PROMPTS" 검색 → Add 또는
    WAN22_PROMPT=원하시는 프롬프트 환경변수 설정
  5. Run All 클릭 (≈14분 소요)
  6. 완료 시 Output 패널에 final_15s.mp4 생성됨
  7. 아래 "결과 업로드" 영역에서 mp4 업로드 → Supabase Storage 저장 → 다운로드 링크

📤 결과 업로드

카글에서 다운로드한 mp4를 업로드하면 라온 시스템이 Supabase Storage에 저장합니다.
