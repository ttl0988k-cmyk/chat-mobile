## 1. 배경 및 목적

`_tmp_discovery_demo` 폴더의 데모 서버에 신규 상품 **'cherry'** 를 추가하고, 이를 문서화(README)하며, API 엔드포인트(`GET /api/items`)가 새 상품을 정확히 반환하는지 자동 검증하는 테스트를 구축한다.

사용자 지시에 따라 **3개 작업(서버 수정 / README 업데이트 / 테스트 작성)은 서로 독립적이므로 병렬로 수행**한다.

> ⚠️ **제약 사항**: 포트 `9090`은 절대 사용 금지 (다온 앱과 충돌). 기본 포트는 `8080` 또는 `5000` 등 대체 포트 사용.

---

## 2. 수용 기준 (Acceptance Criteria)

다음 5개 기준을 모두 만족해야 한다:

| # | 기준 | 검증 방법 |
|---|------|-----------|
| **AC-1** | 데모 서버 소스 코드(`app.py`, `server.py`, `items.js` 등)에 **'cherry'가 상품 목록에 신규 등록**되어 있다 | 소스 코드 내 items 리스트/배열/딕셔너리에서 `'cherry'` 또는 `{"name": "cherry", ...}` 확인 |
| **AC-2** | `README.md`에 **'cherry' 상품이 신규 추가된 항목임을 설명하는 문구**가 포함되어 있다 (상품명, 설명 등 최소 1줄 이상) | README 파일에서 'cherry' 관련 문장 확인 |
| **AC-3** | `README.md`에 기재된 **포트 번호가 실제 서버 listen 포트와 일치**한다 | 서버 기동 후 `netstat` / `curl` / `lsof`로 검증. 코드의 기본값·환경변수 폴백·상수 기준 |
| **AC-4** | `GET /api/items` 엔드포인트 응답 본문에 **'cherry'가 포함됨을 검증하는 테스트 파일**이 폴더 내 존재 | `test_api.py`, `test_items.test.js` 등 파일 존재 확인 |
| **AC-5** | 해당 테스트 실행 시 **통과(pass)** 한다 (exit code 0, 모든 assertion 성공) | `pytest` 또는 해당 test runner 실행 결과 확인 |

## 3. 작업 분해 및 병렬 실행 계획

3개 작업은 **서로 독립적이므로 병렬로 수행**한다. 각 작업의 완료 조건을 명시한다.

### 🛠️ 작업 A: 서버 소스 코드 수정 (cherry 상품 추가)

| 항목 | 내용 |
|------|------|
| **범위** | 데모 서버의 상품 목록 데이터 구조에 'cherry' 아이템 신규 추가 |
| **입력** | 기존 서버 소스 파일 (예: `app.py`, `server.py`, `items.js`) |
| **출력** | 수정된 서버 소스 파일 |
| **포트 제약** | `9090` 절대 사용 금지. 기본 포트는 `8080` 또는 `5000` 등 사용. 환경변수(`PORT`)로 override 가능하도록 구현 권장 |
| **완료 조건** | - 소스 코드 내 items 컬렉션에 `cherry` 항목이 명시적으로 존재<br>- 서버 기동 시 `GET /api/items` 응답에 cherry 포함 (테스트 작업과 연계 검증)<br>- **AC-1, AC-3 충족** |

### 📝 작업 B: README.md 업데이트

| 항목 | 내용 |
|------|------|
| **범위** | README에 cherry 상품 추가 사실 문서화 + 서버 포트 번호 정확히 기재 |
| **입력** | 기존 `README.md` (없으면 신규 생성) |
| **출력** | 업데이트된 `README.md` |
| **필수 포함 내용** | 1. cherry 상품명 및 간단 설명 (1줄 이상)<br>2. 서버가 실제로 listen하는 포트 번호 (작업 A에서 결정한 값과 일치)<br>3. 서버 기동 방법 (예: `python app.py`, `npm start`) |
| **완료 조건** | - README에 'cherry' 관련 문구가 1줄 이상 포함<br>- README의 포트 번호 = 작업 A 서버 코드의 실제 바인딩 포트<br>- **AC-2, AC-3 충족** |

### 🧪 작업 C: 테스트 파일 작성

| 항목 | 내용 |
|------|------|
| **범위** | `GET /api/items` 응답에 'cherry'가 포함되는지 검증하는 자동화 테스트 작성 |
| **입력** | 서버 소스 (작업 A 결과), 포트 정보 (작업 A/B와 일치) |
| **출력** | 테스트 파일 (예: `test_api.py`, `test_items.test.js`) |
| **테스트 내용** | 1. 서버를 테스트 모드로 기동 (또는 test client 사용)<br>2. `GET /api/items` 호출<br>3. 응답 본문에 `'cherry'` 문자열 또는 객체가 포함됨을 assertion |
| **완료 조건** | - 테스트 파일이 `_tmp_discovery_demo` 폴더 또는 하위에 존재<br>- `pytest` 또는 해당 runner 실행 시 exit code 0<br>- **AC-4, AC-5 충족** |
